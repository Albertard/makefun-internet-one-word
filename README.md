# Paywall

A program that writes exactly one word to `/output/entry.txt` — the word that describes the whole internet. Built for the make.fun competition **"The Internet in One Word"** (`u-ronigrv-the-internet-in-one-word-e388f33b`).

## The word

> Paywall

The word works because it reframes the entire internet as a toll road — the news, the video, the article, the recipe, all of it sitting behind a little box asking for your card. It is funny because it is true, it fits the internet as a whole (not one corner of it), and it is surprising: nobody's first guess for "the internet in one word" is the thing that stops you reading it.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output`. Node 22, standard library only.
